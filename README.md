# Lateef Quadri Website

## GitHub Pages setup
1. Create a GitHub account.
2. Create a repository named `YOURUSERNAME.github.io` (replace YOURUSERNAME with your GitHub username).
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then Save.
7. Wait a few minutes, then open `https://YOURUSERNAME.github.io`.

Before publishing, edit the placeholder email/social link in `index.html`.
